# Asynchronous Cooperative Tower Defense (Concept)

An experimental game design concept focused on asynchronous cooperation and shared world defense.

This repository contains a **game design concept and specification** only.
There is **no source code** here.

---

## About this concept

This is an experimental idea for a game focused on:

- Asynchronous cooperation
- Shared world / city defense
- Contributions that matter even without real-time play
- Recording success and failure as history

The purpose of publishing this is very simple:

> I want to know whether this kind of game idea resonates with people.

---

## How you may use this

You are free to:

- Read this specification
- Use the ideas

- Build your own game based on it

I am **not a programmer**, so if you decide to make a game:
